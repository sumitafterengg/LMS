## 🔧 How to Add Content in Open edX Studio

### Step-by-Step Workflow

1. **Open Studio** → http://studio.local.openedx.io
2. **Click on a Course** from the dashboard
3. **Go to "Course" tab** (top nav) → You'll see "Course Outline"
4. **Add Section** → Click "+ New Section" → Name it
5. **Add Subsection** inside the section → Click "+ New Subsection"
6. **Add Unit** inside subsection → Click "+ New Unit"
7. Inside each Unit, add **Components**:
   - **Text** → Rich text / HTML content
   - **Video** → Paste YouTube URL (Open edX auto-embeds it)
   - **Problem** → Multiple choice, checkbox, dropdown, or text input
   - **Discussion** → Forum thread for that unit

### Adding a Video
1. In a Unit → Click **"Video"** component
2. In the video editor, paste the **YouTube URL** in the "Default Video URL" field
3. Open edX will auto-embed — no file upload needed
4. Click **Publish** when ready

### Adding an Assessment
1. In a Unit → Click **"Problem"** component
2. Choose type: Multiple Choice, Checkboxes, Dropdown, or Text Input
3. Write the question and answer options in the editor
4. Set the correct answer and click **Save**
